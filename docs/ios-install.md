# Buff на iPhone через Sideloadly

Приложения Buff ещё нет в App Store. До его выхода iPhone ставится из файла `buff-v<версия>.ipa` [последнего выпуска](https://github.com/buffsystems/buff-mobile/releases/latest) с помощью [Sideloadly](https://sideloadly.io): программа подписывает приложение вашим Apple ID и устанавливает его по кабелю.

## Что нужно

- iPhone с iOS 16 или новее и кабель к компьютеру.
- Компьютер с Windows 10/11 или macOS.
- Apple ID. Подойдёт обычный бесплатный; лучше завести отдельный, не основной.
- Файл `buff-v<версия>.ipa` из [последнего выпуска](https://github.com/buffsystems/buff-mobile/releases/latest).

## Установка

1. Скачайте Sideloadly с [sideloadly.io](https://sideloadly.io) и установите.
   - **Windows:** нужны iTunes и iCloud **с сайта Apple**, не из Microsoft Store. Ссылки есть на странице загрузки Sideloadly.
2. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
3. Откройте Sideloadly. Убедитесь, что в поле **iDevice** выбран ваш iPhone.
4. Перетащите файл `.ipa` на иконку IPA в окне Sideloadly.
5. В поле **Apple account** введите Apple ID и нажмите **Start**. Введите пароль Apple ID и код двухфакторной проверки, если их спросят. Пароль уходит только в Apple.
6. Дождитесь надписи **Done**.

## Первый запуск на iPhone

1. **Включите режим разработчика:** «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика» → включить. iPhone перезагрузится; после перезагрузки подтвердите включение.
2. **Доверьте разработчику:** «Настройки» → «Основные» → «VPN и управление устройством» → ваш Apple ID → «Доверять».
3. Откройте Buff и подключите установку: QR-код или ссылка с кодом из кабинета, админки или Buff Code («Настройки» → «Телефон»).

## Что нужно знать

- **Бесплатный Apple ID подписывает на 7 дней.** Потом приложение перестаёт открываться. Чтобы продлить подпись, снова откройте Sideloadly и нажмите Start с тем же файлом, данные приложения сохранятся. В Sideloadly можно включить автопродление: в Advanced options отметьте **Automatic refresh**, компьютер и iPhone должны быть в одной сети Wi-Fi. С платным аккаунтом Apple Developer подпись действует год.
- **Уведомления не приходят.** Пуш-уведомления Apple доступны только приложениям из App Store и TestFlight. Всё остальное работает, данные обновляются, пока приложение открыто.
- **Ограничения бесплатного Apple ID:** не больше 3 таких приложений на устройстве и не больше 10 новых App ID за 7 дней.
- **Ошибка про расширения или App ID.** Если Sideloadly сообщает об ошибке с app extension или с лимитом App ID, откройте **Advanced options** и отметьте **Remove app extensions**. Расширение нужно только для уведомлений, без него приложение работает.
- **Ошибка «App ID … is not available».** Идентификатор приложения уже занят чужим Apple ID. В **Advanced options** включите **Change bundle ID** и впишите свой, например `systems.buff.app.ivanov`.
- **Ошибка «Guru Meditation» или «lockdownd».** Отключите и снова подключите iPhone, разблокируйте его и снова доверьте компьютеру. На Windows обновите iTunes с сайта Apple.

Когда Buff выйдет в App Store, удалите эту копию и поставьте приложение из магазина: заново подключите установки, данные на телефоне — только кеш.
